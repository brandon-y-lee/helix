# Product notification retirement

Spec #622, Ticket #623 retires Product Waitlist Enrollment and delivery of Product availability and cancellation-link emails. This supersedes the operating promise from Spec #430 and Ticket #437. Existing test and demo links return 404. Products with a historical `waitlist` status display Coming soon and remain unavailable for Checkout.

On a target with either Product notification enrollment contract installed, use the independently verified original owner connection to enroll the existing restricted writer with `supabase/operations/release-bootstrap/enroll_product_notifications_retirement.sql`. Supply the same `writer_role`, `expected_environment` and `expected_project_ref` variables as the other [owner enrollment procedures](../../supabase/releases/README.md). Enrollment alone does not retire the feature. The normal forward release then calls the pinned retirement operation and records the version in the same transaction. The operation disables both purposes, closes legacy and current enrollment, stops publication observations, blocks worker claims and Operator retries, and revokes its own writer grant. A target with neither contract installed takes the verified no-op path.

Historical rows and admitted lease identities remain available for signed reconciliation. For expiry, authorized support admins mark only individually verified demo intent IDs through the [existing synthetic retention procedure](resend-activation.md), then allow its 30-day rule to erase eligible payloads. Unresolved provider outcomes retain their identity and content for reconciliation. No records are automatically marked as synthetic by this release. A message already handed to the provider can still arrive.

Local synthetic PostgreSQL verification uses `node scripts/db/test-product-notification-contracts.mjs <synthetic-postgres-container>`. The fixture exercises the original invariants, then verifies the forward retirement. The browser suite checks 404 responses for the retired routes. Shared email tests cover ordinary delivery and signed reconciliation.
